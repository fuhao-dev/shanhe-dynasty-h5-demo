# 山河纪 · 王朝模拟器 H5 DEMO

基于《游戏系统策划文档》《玩法规则与结算明细》制作的独立可玩原型。用青绿山水、巡天奇遇与群体养成，验证「寻脉 → 聚灵 → 培养仙师 → 提升战力 → 王朝进阶」的循环。

## 立即试玩

- Windows：双击 `启动DEMO.cmd`，或直接用现代浏览器打开 `dist/index.html`。全部资源在本地，无需安装依赖。
- 开发预览：安装 Node.js 18 或更高版本，在此目录执行 `npm start`，访问 `http://127.0.0.1:4173`。
- 静态部署：将 `dist` 目录完整上传到静态网站主机即可。所有素材使用相对路径，也能部署在网站子目录。
- 在线网址与交付状态见 [交付说明](交付说明.md)。

## 怎样玩

1. 点击「开启巡天」。可点击「凝神」加快探索，每 0.75 秒最多生效一次。
2. 在「巡天奇遇」中选择收益或离开。初次寻脉消耗 6 灵璧，获得 2 条龙脉。
3. 灵气够容纳一整批仙师时，各境界自动修炼。通过地图「龙脉」寻访与梳理，提高容量。
4. 在「万象养成」中培养白鹿、功法和剑道，强化仙师战力；精进神念可缩短巡天时间。
5. 「山河志」中的愿景达成后需手动领奖。战力达标后手动点击「王朝进阶」。
6. 从清气初生走到玉泉漱石，完成本卷。终境后可继续经营、导出存档或重新开局。

试玩目标节奏约 5～10 分钟，受操作与阅读速度影响；自动策略模拟不是人工试玩耗时。

## 与完整策划的关系

本原型重新编写，没有导入或运行原版 Cocos/微信编译脚本，也不读取原版资源与存档。旁边的原版目录、恢复开发副本和基线均未改动。

沿用策划的核心因果关系：龙脉决定灵气容量；不同境界消耗不同灵气；按整批培养；已启动批次照常结算；本体与剑修群体战力分别求和；剑修单体先向上取整；百分比加成相加；王朝进阶不扣战力。

以下是明确的试玩调整：

- 巡天 4～8 秒一轮，修炼 3～5 秒一批；阈值、奖励、培养消耗与加成重新配平。
- 青岚诀以玄晶必定升级，省略原版普通升级成功率与完整功法图鉴。
- 剑道只有一条；首次领悟时半数本体转为剑修，新生批次约六成为剑修。省略多仙路、宗门与多身份重叠。
- 白鹿每阶给全部境界各增加 10 基础战力。仅一只灵兽、无灵兽碎片系统。
- 奇遇采用可重复验收的固定序列。宝匣固定收益，聚灵最多招纳 30 位最高已解锁境界仙师。
- 省略战争、仙玉付费、广告、活动、排行榜、账号服务器、社交、音效和商业化。
- 背景标签页暂停在线模拟，转为简单离线玄晶结算；未做离线仙师补算。

供给不足时可能看到少量负灵气余量：不同境界先后启动的批次都会完成，完成后停止启动下一批。这是批次结算的结果。

## 存档

存档键为 `shanhe_h5_demo_v1`，独立于原版与恢复副本。进入「玩法与存档」可导入导出。导入先校验版本、资源、等级、事件与境界，再展示确认，不执行存档文本中的任何代码。

`file://`、本地 HTTP、在线域名、不同浏览器使用各自存档，可用 JSON 转移。浏览器禁用或清理本地存储时，请保留导出的文件。页面内提示“导出”后，可在浏览器下载目录找到 JSON。

## 开发结构

```text
dist/index.html       页面骨架与 SVG 界面图标
dist/style.css        青绿 / 宣纸风格、响应式与动态效果
dist/engine.js        规则、配置、状态、动作、计算与存档校验；不依赖 DOM
dist/app.js           渲染、交互、弹窗、自动保存、导入导出、生命周期
dist/assets/          生成的美术和代码绘制的 favicon
tests/engine.test.cjs  12 项有状态逻辑测试与 600 秒策略模拟
tools/serve.cjs       无依赖的本地静态服务器，只监听 127.0.0.1
.openai/hosting.json  Sites 静态部署配置
```

本项目没有构建步骤，`dist` 内就是可维护源码。新增规则优先改 `engine.js`，界面改 `app.js` 和样式。后续扩展建议先把配置拆出，再增加战争或多仙路，避免一次并入完整原版的全部复杂度。

```powershell
npm.cmd run check
npm.cmd test
npm.cmd start
```
